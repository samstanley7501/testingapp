# Project context

This work is for **Trybe**, a free booking and payments app for independent barbers. Before writing outreach, copy, features or anything customer-facing, read the briefing:

@docs/trybe-briefing.md

Key rules from it:
- Don't invent features, prices, countries or partnerships beyond what the briefing lists.
- Match the voice: casual Aussie barber-to-barber, short, low-pressure.
- Don't ask barbers for passwords or bank details by DM.
